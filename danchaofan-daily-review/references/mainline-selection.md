# 复盘主线选择：A 异动归因 / B 分析框架 + 快评取舍

阶段一的产出全靠这份文件。**主线选错，后面写得再好也白费**——这是这条产线唯一一个"重做成本极高"的决策点，所以它前置、并且交给用户拍。

---

## 一、先明白日更真正的难点

不是"抓不到数据"，是**每天都要有一个值得讲 3 分钟的主线**。

盘面天天有，但"今天有明确主角"的日子大概只占六成。剩下四成是这样的日子：指数涨跌不到半个点、成交额和昨天差不多、板块榜第一名涨 2% 出头、没什么大财报。参考号在这种日子会直说"最近行情无聊，没啥新东西写"（指汇盈 8/26），然后转去写一个**低估值行业的投资逻辑科普**——这就是 B 型主线的来路。

所以主线分两型，不是为了分类学好看，是为了**平淡日子照样有稿可写，不至于硬把 2% 的板块吹成"资金大举涌入"**。硬凑异动是复盘账号掉粉最快的方式：观众自己看得见盘，你把小波动说成大事，他立刻知道你在凑字数。

## 二、A 型：当日异动归因

**一句话定义**：今天有一个足够强的异动主角，整条主线就是把"它今天为什么这样"讲透。

**取材**（按锋利度排序）：

1. **个股级强异动 + 有明确外因**。范例：阳光电源暴跌 12%，因为特朗普签了禁止美国采购外国大型电网级电力设备的行政令，而大型逆变器正是它的主营。这类是最好的 A 型主线——有具体主角、有确定归因、有可延展的风险面（"光模块那几家也小心点"）。
2. **财报暴雷/超预期，且落差巨大**。范例：泸州老窖二季度利润 6.3 亿、同比跌 79% 环比跌 83%；伊利二季度利润只剩 2.67 亿（一查是计提澳优商誉 24 亿）。**这类的价值在于"一查发现另有原因"**——观众看头条只知道暴雷，你讲清是减值还是主营真的崩，这就是信息差。
3. **板块级异动 + 归因不显然**。范例：证券板块涨 3% 领涨行业，但没有明面利好，往回查是 21 家中报累计净利同比 +53% 且多家有现金分红计划。**"没有利好却涨"比"有利好且涨"更值得做主线**，因为前者才有信息缺口。
4. **隔夜海外传导**。范例：英伟达二季报超预期 → 科创 +3.77%、内存需求缺口吃紧 → 国内相关板块普涨。这类要讲清**传导链条**，否则就是搬运新闻。

**A 型的判断标准（写稿前先自问）：**

- 异动强度够不够？个股一般 ±7% 以上、板块 ±3% 以上才撑得起主线。够不上就别当主线，降级成快评。
- 归因**有当日信源**吗？公告、权威媒体、正式披露。搜不到就只能写成"市场普遍归因于……，但没有正式披露"——这句话可以说，但**一整条主线建立在没有信源的猜测上，就不该当主线**。
- 有没有**延展面**？只讲一只票 3 分钟很难不注水。好的 A 型主线一定能往外延一层：同类公司的同类风险、上下游谁受益、这个逻辑还会不会再发生。

**A 型的结构模板**（主线段内部）：

```
异动现象（数字 + 反差）
  → 官方/市场归因是什么
    → 这个归因站不站得住（这里是你的价值，不是搬运）
      → 同样逻辑下还有谁在风险里 / 谁受益
        → 该盯什么信号（不是该买什么）
```

## 三、B 型：可带走的分析框架

**一句话定义**：今天盘面没主角，主线改成讲一个**观众能带走、下次能自己用**的分析框架。

**取材**（这类主线的素材是攒的，不是当天现找的）：

1. **周期框架**。范例：白酒库存四阶段（主动加库存→被动加库存→主动去库存→被动去库存），用小丸子酒厂和经销商的角色扮演讲完，最后落到"现在处在第四阶段"。这是全部参考素材里最好的一段——**把一个抽象周期讲成一个有角色的故事，观众能记住并复用到光伏、猪、锂上**。
2. **纠正一个流传很广的错框架**。范例：那张病毒式传播的"大宗商品顺周期轮动图"（黄金→铜铝→原油→化工→农产品），指汇盈直接说这个逻辑不完全对——**农产品能不能涨不取决于需求，取决于供给**，因为人不会因为有钱就从一晚一碗饭吃到三碗。这类主线的钩子天生就锋利：观众可能正信着那个错框架。
3. **一个反复被问错的关系**。范例："油价上涨究竟利好还是利空化工？"答案是不一定，因为化工厂利润 = 化工品价格 − 原料价格，要看**价差**而不是看油价方向。这类是纯信息价值，且长尾流量好（会被搜索反复捞出来）。
4. **一个宏观变量的拆解**。范例：美国 40 万亿债务怎么化——降息放水/削减福利/赌 AI 生产力/动用美军，四条路各自对黄金意味着什么。

**B 型的判断标准：**

- 观众听完能**复述**吗？框架必须能压缩成一句话（"农产品看供给不看需求"）。压缩不了的框架说明还没想清楚，别上。
- 有**当日抓手**吗？B 型不能悬空讲。8/27 那条讲农产品框架，抓手是"8 月 19 日国家气候中心确认厄尔尼诺将在 11-12 月达峰、为历史最强"——**必须有一个当天或当周的真实事件把框架拽到今天**，否则观众会问"你今天为什么讲这个"。
- 和观众**持仓沾边**吗？讲得再漂亮，如果是他完全碰不到的资产，留存会掉。

**B 型的结构模板**：

```
一个观众可能正信着的说法 / 一个反复被问的问题
  → 为什么它不对 / 为什么答案是"不一定"
    → 正确的框架是什么（要能一句话压缩）
      → 用一个具体例子把框架跑一遍（橡胶、化工价差、白酒库存）
        → 今天的抓手：这个框架对上了什么正在发生的事
```

## 四、四道筛子（3 个候选都要过一遍）

按顺序筛，前面不过后面不用看。

**第一筛 · 持仓相关性**（最重要，也最容易被忽略）
观众是拿真钱的散户。判断标准不是"这事重不重要"，是"**他手里可能有的东西和这事有关吗**"。宇树科技四天从 1100 跌到 600 很刺激，但次新股散户持仓面窄；白酒、券商、光模块、锂电、黄金持仓面宽。同等锋利度下，**选持仓面宽的那个**。

**第二筛 · 信息缺口**
观众今天已经从头条上知道的东西，不构成主线。他知道"泸州老窖暴雷"，不知道"控量保价导致营收利润双降、经销商减少 162 家、之前承诺的 85 亿分红现在压力山大"。**主线要落在他不知道的第二层。**

**第三筛 · 数据支撑真实性**
候选里写的每个数字都必须是**这一轮真抓到的**，不能是印象。这一筛不过就直接毙掉候选——带着错数字进入写稿阶段，终审会打回，等于白跑一遍。

**第四筛 · 合规可讲性**
这个主线能不能在**不给操作建议**的前提下讲完整？如果讲完必然要落到"所以该买该卖"才成立，那它本身就不该当主线。范例反面：指汇盈的电力那条，整条逻辑的落点是"适合刚接触网格的小白关注"——这个落点我们不能要，抽掉落点后那条主线就撑不住了，所以换选题，不是换措辞。

## 五、快评清单怎么定（3-5 条）

快评是复盘的**留存引擎**，不是凑时长的。每条 40-60 秒。

**候选池**（当日抓取里挑）：

- 当日财报（营收/利润 + 一句归因，参考号的主力素材）
- 单个板块或个股的次级异动（够不上主线的那些）
- 政策/监管消息（IPO 窗口指导、行政令、环评）
- 海外事件传导（美债、金价、原油、地缘）
- 公司治理与舆情（裁员、举报、增持减持）
- 一个和钱有关的社会新闻（詹姆斯 3.6 亿美元抵押代言收入借款、新加坡生育补贴）

**取舍标准**：

1. **每条都要有一个"和你的钱有什么关系"的落点。** 没有落点的就是新闻搬运，删掉。
2. **不要五条同质。** 五条全是财报会让中段变成流水账念稿——这正是账号最大短板（中段流失）会被放大的地方。配比上尽量做到：2-3 条硬信息（财报/异动/政策）+ 1 条海外或宏观 + 1 条有点意思的（社会/治理/人的故事）。
3. **顺序按"和观众距离"排**，最近的放第一条。第一条快评是主线之后的第一个留存关口，要用最贴身的那条守。
4. **上限 5 条**，宁少勿多。5-8 分钟里塞 6 条快评，每条都讲不透，等于全废。

**快评的写法要点**（细节在 review-structure.md）：每条开头点名对象，中间给数字，结尾给落点。**绝不能写成"第一，某公司发了财报，营收多少，利润多少。第二，某公司……"** 这种句式复读三次，观众必划走。

## 六、产出格式（阶段一交付给用户的样子）

```
今天盘面：<一句话，含成交额和涨跌家数量级>

主线候选一 · [A 异动归因]
钩子：<一句话，就是将来的第一句>
支撑：<真抓到的数字，标注来源接口/搜索>
持仓相关性：<为什么观众可能碰得到>
延展面：<往外能延到哪一层>

主线候选二 · [B 分析框架]
（同上，B 型要额外写清"今天的抓手是什么"）

主线候选三 · ...

配套快评清单（推荐 4 条）：
1. <对象 + 数字 + 落点>
2. ...
```

给完停下，让用户选。**不要自己替用户挑一个就开始写稿**——这个决策点存在的意义就是让人来拍。

用户如果说"三个都不太行"，那是选题池不够，回去补搜（换角度搜、搜隔夜海外、搜行业媒体），不要把三个候选改改措辞再交一遍。
