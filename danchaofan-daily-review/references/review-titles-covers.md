# 复盘品类的标题公式 + 封面固定模板

复盘是日更，标题和封面的打法和个股深度稿不一样：个股稿一期一个爆点、可以每期换审美；日更靠**系列识别度 + 每期一个新钩子**双轮驱动。固定的部分要死死固定，变化的部分每期都要新鲜。

---

## 一、标题：3 个候选，20 字以内

### 复盘标题的第一大坑：日期流水账

❌ "8月28日A股复盘"
❌ "今日复盘：市场分化明显"
❌ "复盘 | 沪指微涨，两市成交2.1万亿"

这三个是复盘账号最常见的标题，也是流量最差的一类。问题不在于难看，在于**零信息缺口、零情绪、零具体锚**。观众刷到它，没有任何理由停下——他不知道这条视频里有什么他不知道的东西。

日期放在封面的日期条上（见下），**不占标题的 20 个字**。标题的每个字都要用来制造停下来的理由。

### 五个可用公式

按实战锋利度排序，优先用前三个。

**① 数字反差式**（最强）
两个数字对撞，或一个数字和一个常识对撞。
- 「半年赚391亿，市盈率只剩12倍」
- 「券商中报涨53%，股价今年跌11%」
- 「87只涨停，中位数还是绿的」

**② 归因悬念式**（配 A 型主线）
现象 + 一个非常识的原因方向，把答案吊住但给出方向。
- 「阳光电源跌12%，跟业绩没关系」
- 「今天最惨的不是光模块」
- 「白酒又雷了，这次雷在分红承诺上」

**③ 反常识结论式**（配 B 型主线）
直接把反常识的结论当标题。
- 「农产品涨不涨，跟你有没有钱没关系」
- 「油价大涨，化工到底赚不赚钱」
- 「美债要化债，只有四条路」

**④ 对象点名式**
当日主角自带流量时最省力，公司名/板块名放最前。
- 「泸州老窖二季度只赚了6亿」
- 「券商今年第一次领涨」

**⑤ 提问式**（慎用，容易滑成标题党）
只在问题本身就是观众正在问的时候用，且视频必须真的答了。
- 「2万亿量能还守得住吗」——⚠️ 这个例子擦线了，接近"预测大盘方向"，实际写稿时容易被带跑。**能不用提问式就不用。**

### 标题硬规则

1. **20 字以内**，超了就砍修饰词不砍信息。
2. **必须含一个具体锚**：公司名、板块名、或一个具体数字。和首句锚点是同一条约束。
3. **不预测方向**。❌「明天要反弹了」「这里就是底部」——这是复盘品类的合规红线，不只是标题技巧问题。
4. **不用感叹号、不堆叠符号**。账号是严肃财经调查风，不是标题党风。
5. **不做保证性承诺**。必涨、稳赚、闭眼、抄底良机一类词一个都不能出现。
6. **标题定稿后必须回改开头 hook**，让开头兑现标题。这是铁律，两者永远绑定。

### 产出格式

```
候选一：<标题>（<字数>字）
  公式：数字反差式
  推荐指数：★★★★★
  理由：<一句话，讲清它制造了什么信息缺口>

候选二：...
候选三：...
```

三个候选**要走不同公式**，别是同一个说法的三种措辞——那样用户没得选，等于没给候选。

## 二、封面：固定模板 + 每期换主锤判断

### 封面基因（继承账号，不改）

严肃财经调查风：墨黑/炭灰底 + 暖金作为唯一强调色，极粗黑体，真实物件摄影 + 颗粒质感。不用蓝紫渐变、不用发光科技风、不用卡通元素。

### 复盘子栏目的固定排布

日更靠固定排布攒系列识别度——观众刷到第五次的时候，**不看标题就知道这是蛋炒饭的收盘复盘**。所以下面这套排布每期照搬，别即兴换。

```
┌─────────────────────────┐
│  ▌08.28 收盘复盘         │  ← 日期条：左上角，暖金细条 + 白字，
│                         │     固定位置固定字号，全期一致
│                         │
│     [真实物件主视觉]      │  ← 主视觉：和当日主线相关的实物
│                         │     （酒瓶/铜锭/粮袋/变压器…）
│    ██████████           │
│   主锤判断 + 一行短句     │  ← 主锤判断：极粗黑体，暖金或白，
│    ██████████           │     占画面 1/4 以上，是全图视觉重心
│                         │
│              蛋炒饭财经   │  ← 账号署名：右下角小字，固定
└─────────────────────────┘
```

三个固定元素（**日期条 / 主锤判断 / 右下署名**）位置和样式全期不变；一个变化元素（**主视觉实物**）每期跟着主线换。

### 主锤判断：唯一的硬规则

**封面主锤必须是一个具体实锤，不能是抽象意象。**

这条不是审美偏好，是账号横评数据实锤出来的：唯一一支封面明显崩掉的视频（茅台那条，CTR 4.90%）就是用"拧酒瓶挤水分"这种抽象意象，观众 0.5 秒读不到任何具体信息。缩略图尺寸下，抽象意象传达不了任何东西，具体实锤能。

定封面前问一句：**观众在 0.5 秒内能读到一个具体的东西吗？** 读不到就重做。

主锤判断的取材：
- 主线里那个最刺的数字（`391亿`、`-79%`、`12倍PE`）
- 一句当日最锋利的判断（`算力没崩，崩的是信仰`、`业绩好的反而跌`）
- 反差对（`+53% / -11%`，两个数字上下排，中间一道暖金分隔）

主锤判断旁边的短句**不超过 8 个字**，只做注解（`半年利润`、`二季度环比`），不重复标题。

### 提示词写法

`generate_cover.py` 吃自然语言画面描述。复盘封面的提示词模板：

```
严肃财经调查风格封面。墨黑到炭灰的渐变背景，暖金色作为唯一强调色，
明显的胶片颗粒质感。画面中央是<当日主线相关的真实物件>，
侧光打亮，背景压暗。整体氛围冷峻、克制、有纸质印刷感。
不要科技蓝紫渐变，不要发光特效，不要卡通元素，不要任何文字。
```

**关键：提示词里明确要求"不要任何文字"。** 模型生成的中文字几乎必然是错的或糊的，日期条和主锤判断后期叠上去，不交给模型。

两个尺寸各出一版：
```bash
python3 "$DESK/scripts/generate_cover.py" --platform bilibili \
  --prompt "<上面的提示词>" \
  --output "$DIR/封面/<最终标题>_bilibili.png"     # 4:3

python3 "$DESK/scripts/generate_cover.py" --platform douyin \
  --prompt "<上面的提示词>" \
  --output "$DIR/封面/<最终标题>_douyin.png"       # 3:4
```

3:4 竖版的构图要重新想，不是把 4:3 裁一刀——竖版里主视觉在上、主锤判断在中下，日期条仍在左上。

### 主视觉取材对照（省得每期现想）

| 主线类型 | 主视觉候选 |
|---|---|
| 白酒 | 酒瓶、酒盒、仓库里的纸箱堆 |
| 券商/大盘 | 交易大厅座椅、成交单据、算盘 |
| 有色/矿业 | 铜锭、金条、矿石 |
| 农产品 | 粮袋、橡胶割口、干裂的土地 |
| 电网/电力 | 变压器、高压塔、逆变器机柜 |
| 光模块/芯片 | 光纤束、晶圆、机房冷通道 |
| 消费 | 便利店冷柜、瓶装饮料、外卖箱 |
| 宏观/美债 | 美元纸币、国债凭证、政府大楼外墙 |

无主视觉可用时（纯宏观框架类），退回**纯排版封面**：墨黑底 + 巨大主锤判断 + 暖金细线，不硬塞不相关的实物照。

### 关于 API key

`LLM_GATEWAY_API_KEY` 已固化在 `$DESK/.env`，`generate_cover.py` 自动读取，**直接跑，不要向用户索要 key**。

万一脚本真的报「未找到 LLM_GATEWAY_API_KEY」，**不要卡住流程**：把两版提示词和主锤判断方案写进 `视频基础信息.md` 的封面小节，提醒用户配 key 后再跑，然后继续走阶段四。
