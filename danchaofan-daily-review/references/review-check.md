# 复盘稿终审清单（独立子 agent 执行）

**这份清单由一个独立的审核子 agent 执行，不是写稿的人自己扫一遍。** 写稿的人对自己的稿子有盲区，尤其对"我以为我讲透了"这件事。终审的价值全在独立性上。

**给子 agent 的五样输入**（缺一样就退回补齐，别硬审）：
1. 定稿口播稿全文；
2. 受众画像（`$WORKSPACE/huasheng.md` 第三节）；
3. 当日盘面数据（`参考资料/抓取数据/market_snapshot.json` + 本轮搜索结论）；
4. `huasheng.md` 第八节流量认知；
5. 本文件 + `$DESK/references/banned-words.md`。

**输出要求**：**逐条给核查结论，不接受"已检查、合规"这类自评断言。** 每一条都要写"查到了什么"。前三层任一条不过 → 判 REJECT 并指明具体位置和改法；三层全过 → 判 PASS，再做第四层流量预测。

主流程只认 PASS，拿不到就打回重写、改完重审。

---

## 第一层 · 事实与数据核查（不过就是废稿）

复盘讲的是当天的钱，数字错一个就毁掉信任，而且日更意味着错误会被隔天的观众抓出来。

**1.1 每个数字都能溯源。** 逐个数字对照 `market_snapshot.json` 和搜索结论。稿子里出现、但抓取数据里找不到的数字，一律标出来要求补证或删除。**"这个数看起来对"不是理由。**

**1.2 数据口径没有被夸大精度。** 这一条是复盘品类专属，最容易出错：
- 涨跌家数：精确值，但口播必须四舍五入到顺口量级。出现"2796 只上涨"这种到个位的表述 → 改。
- **市场中位数：抽样近似值。** 稿子里只能出现方向和量级（"中位数微涨""中位数跌了一个多点"）。出现"中位数上涨 0.13%"这种精确小数 → **REJECT**，这是把抽样值当精确数据用。
- `median_sign_consistent` 为 false 时，稿子里还在用中位数说事 → 改成用涨跌家数。
- 成交额：只有沪深两市合计一个口径，不能出现自行相加第三个指数的痕迹。
- 板块涨跌幅：雪球口径，且行业板块和概念题材不能混成一张榜念。

**1.3 归因有当日信源。** 主线和每条快评的因果关系，都要能指到一个当日信源（公告/权威媒体/正式披露）。没有信源却写成确定归因 → 改成"市场普遍归因于……，但没有正式披露"。
- 特别查**万能归因**："受市场情绪影响""获利盘了结所致""资金博弈激烈"——这些不是归因，是把"不知道"说得体面。出现即改成如实承认。

**1.4 财报数字的同比环比口径对得上。** 参考素材里的高价值写法（"二季度单算利润 6.3 亿，同比跌 79%，环比跌 83%"）容易在转写时算错。逐个复核：单季度是不是真的从半年报里减出来的、同比比的是不是去年同期。

**1.5 没有占位符和未完成句。** "（此处补数据）""具体数字待核实"一律 REJECT。

## 第二层 · 合规红线（不过就是废稿）

### 2.1 继承的账号红线（全部适用）

- 不给具体买卖点位、目标价、止盈止损价；
- 不给分人群操作指令（"仓位重的可以……""还没上车的等……"）；
- 不转述研报目标价（"某机构上调目标价至 X"——**转述也算给目标价**）；
- 不做保证性承诺：必涨、稳赚、闭眼买、安全边际、确定性机会、这个位置很安全；
- 正文不出现股票代码；
- 结尾必带风险提示。

### 2.2 复盘品类专属红线（本产线最容易踩）

**① 不预测指数点位、不给大盘方向断言。**

逐句扫有没有这类表述：
- ❌ "下周要反弹到 4100 点"
- ❌ "这里就是底部了"
- ❌ "量能见底了，接下来要起来了"
- ❌ "这波调整差不多到位了"

改法是**换成该盯的信号**：
- ✅ "成交额能不能在 2 万亿上方站住、融资余额回不回来，这两个没看清之前我不下结论。"

> 为什么这条比个股荐股更需要盯：它没点名任何股票，听起来像"分析"，实际是在给全体观众一个可执行的方向指令，而且观众照做的规模比单只票大得多。**隐蔽性更高，危害不小。**

**② 板块只做归因，不做配置建议。**

- ❌ "农牧渔 ETF 值得关注"
- ❌ "这个板块适合刚接触的小白关注"
- ❌ "建议搭配网格策略使用"
- ❌ "可以均衡分散配置摊大饼"

这四句是从参考公众号里逐字摘出来的**反面例句**。参考文档是内容结构的参考，不是合规尺度的参考——**抄骨架，不抄这个。** 审到类似句式一律 REJECT。

- ✅ "今天农业板块领涨，直接原因是国家气候中心 8 月 19 日确认厄尔尼诺会在年底达峰。这个逻辑影响的是供给端，所以要看的是后面主产国的产量数据。"

判定标准一句话：**帮观众看懂今天为什么这样、该盯什么 = 内容；替观众判断明天怎么走、该买什么 = 荐股。**

**③ 情绪段红线。**
- 未坐实的负面定性（"某公司造假""某人跑路"）→ 改成"有投资者质疑""市场传闻，尚无正式披露"；
- 敏感政治议题的立场评价 → 只留对市场的传导链条；
- 传谣当真 → 删；
- **消费灾难和苦难**（天灾人祸、伤亡事件当情绪素材）→ **REJECT，这是底线不是尺度**。

## 第三层 · 内容质量（不过就是平庸稿，也打回）

**3.1 首句锚点。** 首句必须含具体锚：主角公司名 / 板块名+数字 / 具体市场数字。只有"今天大盘""今天市场"这类泛指 → REJECT。
> 首句会变成自动字幕，是搜索推荐匹配的第一手素材。这条是硬约束。

**3.2 Hook 与标题互相兑现。** 标题承诺的信息缺口，开头 5 秒内接上了吗？标题一个说法、开头讲另一件事 → REJECT（这种流失发生在前 5 秒，最伤）。

**3.3 主线走到第二层了吗。** 
- 第一层 = 观众看头条已经知道的（"泸州老窖暴雷了，利润跌 43%"）；
- 第二层 = 为什么会这样（控量保价、经销商退了 162 家）；
- 第三层 = 接下来的连锁反应（85 亿分红承诺补不上，洋河去年改过承诺后股价暴跌）。

**只到第一层 → REJECT。** 这是复盘稿最常见的平庸原因。

**3.4 主线结论收在"该盯什么"，不是"该买什么"。** 既是合规也是质量——给信号比给结论有复用价值。

**3.5 快评质量。**
- 数量 3-5 条；
- 每条有"跟你的钱什么关系"的落点，没落点的是新闻搬运；
- **不是五条同一个句式**（"第一，某公司发了财报，营收 X 利润 Y" 复读三遍 → REJECT）；
- 第一条快评是持仓面最宽的那条（主线结束是天然流失点，要用最贴身的守）。

**3.6 字数与配比。** 总字数 1500-2400。大盘段不超过 180 字。主线 700-1000 字。快评各 150-220 字。情绪段 180-250 字。哪一段严重超配就指出来。

**3.7 AI 味逐句扫。** 过 `$DESK/references/banned-words.md`，外加复盘专属五类：
- 财经八股（"市场情绪谨慎""结构性行情延续""板块轮动加速"）——判断法：**这句话换到任何一天都成立吗？成立就是废话**；
- 万能归因（见 1.3）；
- 排比式总结（"既是挑战也是机遇""短期看情绪中期看业绩长期看格局"）；
- 程度副词堆叠（"非常明显地大幅"）；
- 教师腔（"我们需要认识到""值得注意的是""这里给大家科普一下"）。

**3.8 交付格式。**
- 零结构标注（无【】小标题、无时间轴、无"（画面：…）"）；
- 中文全角标点；
- 数字用阿拉伯数字、四舍五入到顺口量级、`%` 用半角；
- 无股票代码；
- 默念一遍：需要在心里断两次才顺的句子 = 书面语，指出来。

## 第四层 · 流量预测（PASS 之后做，不是门禁）

**先读 `huasheng.md` 第八节。** 核心认知：**涨粉率 ≈ 平均播放时长，和播放量几乎不相关**（9 支样本）。所以这一层评的是留存，不是"能不能爆"。

### 三段自评

**① 前 5 秒（决定上限）**
- 首句有没有具体锚 + 数字？
- 信息缺口够不够大——观众有没有"我不知道这个"的感觉？
- 有没有"我需要等一下才知道讲什么"的劝退感？

**② 中段留存（决定涨粉，这个账号最大的短板）**
- 主线段每 40-50 秒有没有小转折/路标？
- 快评的编号和引信有没有起到进度条作用？
- 有没有连续 60 秒以上只在念数字的段落？
- 第一条快评够不够贴身？

**③ 结尾（决定关注转化）**
- 情绪段是不是真的有人味，而不是又一段分析？
- 价值锚 + 具体互动问题都到位了吗？（互动问题要具体到能回答，"欢迎评论"不算）

### 落档预测

给一个定性判断 + 短板清单：

```
留存预期：偏强 / 中性 / 偏弱
最强的一段：<哪一段，为什么>
最可能流失的位置：<具体到段，为什么>
如果只改一处：<改哪里>
```

### 复盘品类的基准线还没有（如实写，别假装）

`huasheng.md` 第八节的 9 支样本**全部是个股深度稿**，复盘是新品类，播放/完播/涨粉的分布还没有观测值。所以：

- **前 5-8 期只做定性预测**，不给"预计播放量 X 万"这类数字——那是编的。
- 每期发布后走 `danchaofan-data-tracker` 抓数据落档；
- **跑够 5-8 期后回写 `huasheng.md` 第八节的复盘基准线**，之后这一层才能给量化预测。

在此之前，第四层的输出如实标注"复盘品类基准线未建立，本预测为定性"。

```

1.3 归因信源：<每条归因指到哪个信源>
1.4 财报口径：<复核结果>
1.5 占位符：<有/无>

## 第二层 合规
2.1 账号红线：<逐项>
2.2① 指数预测：<逐句扫的结果>
2.2② 板块配置建议：<逐句扫的结果>
2.2③ 情绪段：<逐项>

## 第三层 内容质量
3.1-3.8：<逐条>

## 判决
PASS / REJECT
（REJECT 时列出必改项，指明位置和改法）

## 第四层 流量预测（仅 PASS 时）
<三段自评 + 落档预测 + 短板；标注基准线状态>
```

判决和第四层预测原文写进 `视频基础信息.md` 的「四、终审记录」和「五、投稿前流量预测」。曾被打回过的，在终审记录里简述改了什么——这是下一期避免重复踩坑的线索。
