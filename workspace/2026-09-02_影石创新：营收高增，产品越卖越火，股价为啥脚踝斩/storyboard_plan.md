## 一、成片需求（含画风设计）

### 📋 基础信息
- 视频标题：影石创新：营收高增，产品越卖越火，股价为啥脚踝斩
- 内容摘要：影石创新产品卖爆全球——上半年营收 55 亿、同比涨 50%、全景相机市占率 71%，股价却从 377 块跌到 113 块、市值从 1400 亿跌到 454 亿。本片拆解"越卖越亏"的三大坑：存储涨价、大疆价格战、自己烧钱扩张，判断三者性质不同，收口到产品力与市销率估值，给出三个跟踪信号。
- 画幅 / 主发平台：9:16 竖屏（抖音主发）
- 年代背景：现代（2025—2026）
- 参考风格：严肃财经调查 / 深度解说
- BGM 需求：贴合"看跌警示 + 反转拆解"的克制紧张感，中段拆解段落（存储 / 大疆 / 产品力）稍舒缓。

### 🎥 素材要求
- 本次可用素材类型：`a-roll` / `cloud` / `web` / `meme` / `gen-img`
- 素材偏好：真实空镜留白给 MG 叠加；数据画面统一深色底 + 暖金数字；避免素人正脸（门店排队/时代广场场景取全景或背影）。

- 时效性：使用近两年（2024—2026）素材。
- 地域 / 范围：中国（科创板）+ 全球门店（东京 / 纽约）背景。
- 专名要求：影石创新（Insta360，科创板 688775）、大疆（DJI）、Osmo 360、X5、英伟达、三星 / 海力士 / 美光、立讯精密 / 京东方 / 歌尔股份。

### 🎨 画风
- 账号固定层：墨黑/炭灰打底 + 暖金点缀；标题/金句用极粗黑体（装饰性可用衬线宋体），正文/数据标注用无衬线黑体，数字用等宽感 semibold；图标克制线性、财经质感。
- 情绪偏移：看跌 / 警示——压暗 + 警示黄/红，承载"业绩好、股价却暴跌七成"的焦虑反差。
