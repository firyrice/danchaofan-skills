# 选板块方法论（阶段零 · 从全市场板块榜反推该做哪个板块）

> **本文是增量层。** 选板块和个股产线的「选股」是同一道工序的板块版，**先完整读 `$DESK/references/stock-discovery.md`**（第一性原理、四信号模型的原型、避坑规则、两栏输出格式、子 agent 派单结构），本文只写板块与个股的差异。通用件里没被本文覆盖的条款一律照旧生效。
>
> **三道工序别混**：阶段零「选板块」解决**做哪个板块**（板块未定 → 全市场板块榜里挑一个）；阶段一「选题」解决**这个板块用什么角度做**（见 [sector-topic-selection.md](sector-topic-selection.md)）；两者之间是用户拍板。

---

## 一、板块题的一个优势和一个短板（决定整套判据）

第一性原理继承通用件：**本账号吃的是「持仓焦虑流量」，不是「话题热度流量」**。板块题在这条原理下有一组特有的强弱项，是本文全部判据的来源。

**优势 · 群体共鸣乘数。** 个股题的持仓焦虑是"一个人亏"，板块题是"一大群人一起亏"。通用件 `topic-selection.md` 讲的"对立与共鸣"在板块题上天然放大：一个板块跌 8%，评论区不是一个人在骂，是一片人在对号入座。跨平台势能（尤其视频号转发场景"转给同样套着的朋友"）比单票强。

**短板 · 缺"我"。** 板块是抽象名词。观众心里没有"电网设备"这个仓位，只有"思源电气"这个仓位。个股题天生自带"我手里那只"，板块题必须人为造出来。

**由此得出本产线第一条硬规则：候选板块必须能点出 2-3 只散户持有面广的代表股，点不出的直接砍。** 判据不是"这个板块重要"，是"这个板块里有没有一只观众一听名字就知道自己有没有"。全是冷门小盘的板块（很多细分申万三级行业就是这样），涨跌再猛也做不成一条能吸粉的稿——因为没人能对号入座。

## 二、四信号（与通用件 A/A2/B/C/D 一一对应，判据换成板块口径）

权重关系照旧：**A 与 A2 是"与"的关系、并列最高**，两者都强才进推荐位；A 强 A2 弱（有焦虑但全网讲烂了）除非拿得出独家框架，否则不进推荐位；A 弱的最多进热度破圈榜。板块版把通用件的信号 B 提权了，原因见下。

### 信号 A · 持仓覆盖 × 波动幅度（最高权重）

三件事一起看：

- **波动幅度**：近一周板块涨跌幅 **>±5% 为强**、±3-5% 为中、±3% 以内基本撑不起一条 10 分钟的深度稿（那是每日复盘的量级，让给 `danchaofan-daily-review`）。取 `sector_board.py --sector <名> --period week` 的 `period_percent`（板块指数官方值），或板块榜的 `--period week` 排序。
- **代表股的家喻户晓程度**：板块里有没有散户人尽皆知的票。用成分层的 `leaders_by_cap` 看市值排序，用 `followers`（雪球关注数）看散户持有面——**关注数几十万的票就是"一听就知道自己有没有"的票**（实测特变电工 49 万、中国西电 24 万、国电南瑞 21 万，这三个撑得起代入；关注数几千的小盘票撑不起）。
- **板块体量**：成分股数量与板块总市值（`member_count`、`market_capital_yi`）。太小的细分板块波动再大也只是几只票在动，本质是个股题，该走 `bilibili-finance-video`。

**跌得狠 + 代表股家喻户晓 = 焦虑最浓，这是本产线最好的选板块。** 涨得猛的板块也做，但情绪是"踏空的不甘"而不是"套牢的焦虑"，量级通常低一档。

**护栏（对应通用件的宇树教训）**：**纯题材概念板块（供销社、某某元宇宙这类）→ 信号 A 判弱**。它们波动最猛，但成分股大多是散户没有存量持仓的妖股，涨跌跟观众的钱没关系。这类只能进热度破圈榜，且必须标注"参考宇树，可能吸粉/完播差"。

### 信号 A2 · 独家性余量（与 A 同权重）

问一件事：**这个板块是不是全网每天都在讲？** 板块版的高危名单比个股更集中——**AI 算力、创新药、机器人、军工、固态电池**这几个，每天有几十个财经号在做，独家认知增量摊薄到零。

判断手段：`web_search.py` 搜「<板块名> 分析 / 为什么涨 / 后市」看同类内容密度。

**独家性余量不足时，唯一的救法是拿出全网没有的框架**，板块题恰好有三种现成的独家框架（这是板块产线相比个股产线的结构性优势）：

1. **产业链价差表**——别人讲"涨价利好该行业"，你算清上中下游各自赚的是价还是被挤。
2. **库存周期阶段判定**——别人讲"景气回升"，你说清现在处在四阶段的第几阶段。
3. **伪概念清单**——别人讲"板块整体受益"，你逐个查披露的业务占比，指出哪几家只是名字沾。

三个框架都拿不出，就换板块。

### 信号 B · 驱动事件清晰度（板块新增，权重高于个股版）

**这周的动因能不能一句话讲清，且有权威信源坐实。**

个股稿即便动因模糊，还能靠讲基本面和估值撑满 10 分钟。板块稿不行——**板块稿的全部信息价值就在归因**，因果链缺一环整条稿子塌，只剩念板块涨跌榜。所以这条在板块版是**准入门槛**而不是加分项。

强弱示例：

- **强**：「特朗普签行政令禁止美国采购外国大型电网级电力设备」——一句话讲清、有行政令原文、能往下延展到"哪几家的出口占比高"。
- **强**：「国家气候中心确认厄尔尼诺 11-12 月达峰、为历史最强」→ 农产品供给逻辑。
- **中**：板块涨 3% 但没有明面利好，往回查是中报集体超预期——**"没有利好却涨"信息缺口更大**，只要查得出真原因就是好主线。
- **弱（砍掉）**：「资金轮动到低位板块」「市场风格切换」——这不是归因，这是把"不知道为什么"换个说法。

坐实要求：公告、行政令原文、监管/部委发布、期货交易所价格、行业协会数据、权威实名媒体。搜不到就只能写"市场普遍归因于……但没有正式披露"——这句话可以出现在稿子里，但**整条稿子建立在没有信源的猜测上，这个板块就不该做**。

### 信号 C · 账号适配度

读 `$WORKSPACE/` 下已有视频文件夹（**含个股稿**，一支个股稿其实已经消耗了它所属板块的新鲜度）：

- **去重**：这个板块最近做过没？做过的要同时满足两条才重做——① 间隔月级别以上；② 这轮有新的驱动事件（不是同一个事件再讲一遍）。上个月刚讲过电网设备被行政令砸，这个月又讲同一个行政令，就是没新料。
- **产业链轮换**：不只避免连做同一个板块，**要避免连做同一条产业链**。上周讲光伏设备、这周讲硅料，观众听着是同一件事。
- **落不进 [sector-topic-selection.md](sector-topic-selection.md) 七类选题池的砍掉。**
- **评论区反哺**：复盘产线的固定互动语是「你手里现在最难受的是哪个板块，评论区说一下」——**那些评论就是观众亲口点的板块题**。扫已发视频的 `评论回复.md`，被反复喊的板块直接进候选。这是本产线独有的一路选板块来源，别浪费。

### 信号 D · 数据支撑硬门槛

至少凑齐三样才算过：**驱动事件（有信源）+ 板块行情（`sector_board.py` 板块层）+ 3 只龙头的当日数据（`xueqiu_quote.py`）**。缺任一样都是标题党。

板块估值分位（信号维度 4）**接口拿不到，只能靠搜索**，搜不到就如实标"未获取到"、这一维在稿里不讲。这不影响准入——但如果这条板块的角度本身就是"估值分位"型选题，那分位数据搜不到就等于角度不成立，换角度。

## 三、避坑规则（板块版追加，通用件那几条照旧生效）

- **别把每日复盘的料拿来当板块稿。** 单日板块涨跌 2-3% 是复盘产线的快评素材，不是 10 分钟深度稿的主线。板块稿的量级门槛是**周级别的 ±5%**，或者虽然波动不大但有一个能讲透的结构性变化（十年零涨幅、产能出清完成）。
- **概念板块和行业板块别混着报。** `sector_board.py` 已经分两栏返回，输出清单时也分开——"行业板块跌得最狠的是电网设备，概念题材涨得最猛的是某某"，观众听得出层次。
- **两个口径打架时那正是选题。** 板块指数官方 `percent` 和成分层 `percent_weighted` 差得远，说明涨跌高度集中在少数票。实测电网设备官方 +0.3%、成分市值加权 -0.47%、而思源电气单只 -6.69%——**"板块看着平静，龙头在崩"本身就是一条锋利的选题**，别只看板块涨跌幅就放过。
- **风险预警/伪概念揭穿型别连做**（继承通用件）：泼冷水最容易出爆款，连着做会显得唱空成癖。
- **拥挤度是反向信号**：一个板块涨了半年、换手飙升、全网都在讲，信号 A2 判弱的同时，"拥挤度"本身可以变成风险提示型选题——但那条稿的落点必须是"该盯什么信号"，不是"该不该撤"。

## 四、合规红线（贯穿选板块阶段）

产出的"为什么适合""开场钩子雏形""建议方向"都必须落在**"这个板块为什么动、逻辑成不成立、该盯什么"**，绝不能出现：

- ❌ "××ETF 值得关注""这个板块可以配置""适合小白布局"——**板块配置建议是本产线最容易不自觉写出来的荐股**。
- ❌ "这几只里最受益的是 XX""龙头首选 XX"——龙头排序式推荐。
- ❌ 任何目标价、点位、涨幅空间。

✅ 钩子雏形可以写「电网设备一周跌 12%，手里有思源电气的现在该看什么」，不能写「电网设备跌到位了可以布局」。

## 五、输出格式（两栏，各 3-5 个候选，然后停下）

```
## 🎯 持仓焦虑流量榜（推荐 · 本账号最稳的量）

### 候选 1：<板块名>（行业板块 / 概念题材 · <BK码>）
- **本周表现**：<近5日涨跌幅 X%，当日 Y%，成交额 Z 亿，涨 A 家跌 B 家，主力净流入 C 亿>（标注哪些来自接口、哪些来自搜索）
- **代表股（必填 2-3 只）**：<名字 + 市值 + 本周涨跌幅 + 雪球关注数>，一句话说清为什么观众可能拿着
- **驱动事件**：<一句话讲清动因 + 信源（行政令/公告/部委发布/期货价格，注明来源与时间）>
- **为什么适合本账号**：<持仓覆盖面 × 波动幅度，带关键数字>
- **命中动机**：恐惧 / 愤怒 / 希望（哪一种，一句话说清戳哪根神经）
- **独家性余量**：<高/中/低 + 若低，写出打算用哪个独家框架（价差表/周期阶段/伪概念清单）>
- **建议选题方向**：<七类板块选题池里的哪一类 + 一句话角度>
- **流量预判**：⭐⭐⭐⭐☆ · 弱/及格/爆 哪档 + 对标已发的哪一支
- **开场钩子雏形**：<含板块名 + 代表股名 + 数字或反差的第一句（不含任何配置/买卖建议）>
- **状态标注**：<该板块/该产业链最近做过没 · 数据齐不齐 · 估值分位有没有拿到>

### 候选 2：...（共 3-5 个）

## 🔥 热度破圈榜（高风险高回报 · 蹭当下热点）

### 候选 1：<板块名>
（同结构。纯题材概念板块、无存量持仓盘的放这里，状态标注注明"破圈流量但可能吸粉/完播差，参考宇树"）
```

**每个候选给完，末尾一句话邀请用户挑一个**，例如：

> "想做哪个板块？定了我就按它进选题阶段出 3 个角度。也可以说'再挖几个跌得惨的''只看有政策驱动的''候选 2 换个角度'。"

然后**停下来**——不自动往下出角度、不建视频文件夹。

用户说"三个都不太行"，是候选池不够，回去补搜（换 period 看月线、翻概念板块、搜隔夜海外政策、翻评论区呼声），**不要把三个候选改改措辞再交一遍**。

## 六、派子 agent 跑整段选板块（主 agent 只拿回两栏清单）

整段扫板块榜的活儿**派给一个「选板块子 agent」跑完**。原因：134 个行业板块 + 600 多个概念板块的行情 JSON、单板块深挖的上百只成分股、多条 web_search 全文、workspace 扫描累起来几万字，直接读进主上下文会拖垮后面写稿。

**派给「选板块子 agent」的任务指令**（照此措辞下发）：

> 你是「蛋炒饭财经」的选板块助手，任务是扫全市场板块榜反推这周该做哪个板块，只回传一份两栏推荐清单。
> 1. 定位四个变量：`SKILL_DIR="$HOME/.claude/skills/danchaofan-sector-video"; [ -d "$SKILL_DIR" ] || SKILL_DIR="$HOME/.codex/skills/danchaofan-sector-video"; REPO="$(dirname "$(cd "$SKILL_DIR" && pwd -P)")"; WORKSPACE="${DANCHAOFAN_WORKSPACE:-$REPO/workspace}"; DESK="$REPO/bilibili-finance-video"; [ -d "$DESK" ] || DESK="$HOME/.claude/skills/bilibili-finance-video"`
> 2. **先完整读 `$DESK/references/stock-discovery.md`，再读全 `$SKILL_DIR/references/sector-discovery.md`**（后者是板块版增量层，判据以它为准），严格照它打分和产出。
> 3. **抓数据**：
>    - `python3 "$SKILL_DIR/scripts/sector_board.py" --period week --top 20 --out /tmp/sector_week.json` 拿行业+概念两栏的近 5 日涨跌榜（板块指数官方值）。首尾两端都是候选富矿：跌得狠的是焦虑，涨得猛的是踏空。板块层全挂时退回 `"$DESK/scripts/web_search.py"` 搜「本周板块涨幅榜 主力资金流 最新」兜底，别卡住。
>    - 对收敛出的 shortlist（一次 5-8 个），逐个跑 `python3 "$SKILL_DIR/scripts/sector_board.py" --sector <板块名> --period week --out /tmp/s_<名>.json` 拿成分层：涨跌家数、主力净流入、`leaders_by_cap`（含市值/PE/雪球关注数，判断代表股家喻户晓程度）。
>    - `python3 "$DESK/scripts/web_search.py"` 逐个搜驱动事件与信源：「<板块名> 为什么涨/跌 最新」「<板块名> 政策 2026」「<板块名> 龙头 业务占比」。**信号 B 是准入门槛，动因搜不到信源的候选直接砍掉，不要带进清单。**
>    - 读 `$WORKSPACE/`：列已有视频文件夹名与日期做去重（含个股稿所属板块）+ 看产业链分布做轮换 + 读 `$WORKSPACE/huasheng.md` 第八节对齐流量规律 + **扫已发视频的 `评论回复.md` 找被反复喊的板块**（复盘产线的固定互动语就是问这个，那是观众亲口点的题）。
> 4. **按四信号打分 → 只回传两栏输出**（🎯 持仓焦虑流量榜 / 🔥 热度破圈榜，各 3-5 个，字段照本文第五节格式，**代表股 2-3 只和驱动事件信源是必填项，缺了的候选不要放进推荐位**），末尾附一句邀请用户挑一个的话。**回传总量控制在 3000 字以内，不要把板块榜原始 JSON、成分股清单、搜索全文带回来。** 数据抓不到就如实注明"XX 未获取到"，别用记忆里的旧数据冒充。

若环境实在起不了子 agent，退而在主 agent 直接跑，但**务必降配**（`--top 8`、shortlist 压到 3-4 个），每跑完一个脚本立刻提炼、别把原始 JSON 留在上下文里。
