# 板块选题增量层（阶段一 · 板块已定，出 3 个角度）

> **本文是增量层。先完整读 `$DESK/references/topic-selection.md`**——好问题三问、动机（恐惧/愤怒/希望）、第一·五层对立与共鸣、比较优势五种、第二·五层独家性门槛、反直觉与差异化角度、准入自检七条，**全部照旧生效**。本文只做两件事：**换掉选题池**（个股七类 → 板块七类），**追加板块专属的准入项**。

---

## 一、通用件里对板块题格外重要的三条

不是新规则，是提醒哪几条在板块题上权重更高。

**① 第一·五层「群体共鸣」板块题天生达标，但要点名到人。** 通用件说"能不能在开场一句话里点出一个具体人群规模或共同遭遇"——板块题的人群天然存在（"一个板块跌 8% 是一大群人一起亏"），但**抽象的"一大群人"不算点名**。合格的点名是「手里有思源电气的」「拿着光伏三年的」「上个月刚追进去的」——**必须落到一只具体的票或一个具体的时点**，否则群体共鸣只是句空话。

**② 第二·五层「独家性」在板块题上有三种现成解法。** 通用件说独家性有"独家框架"和"共识聚合"两种来源。板块题多出三种可复制的独家框架（也是本产线相比个股产线的结构性优势）：

- **产业链价差表**——别人讲"涨价利好该行业"，你算清上中下游各自赚的是价还是被两头挤。
- **库存周期阶段判定**——别人讲"景气回升"，你说清现在处在四阶段的第几阶段。
- **伪概念清单**——别人讲"板块整体受益"，你逐个查披露的业务占比，指出哪几家只是名字沾。

三种都是"有数据就能做出来"的框架，不依赖灵感。**AI 算力、创新药、机器人这类全网天天讲的板块，不带这三样里的任何一样就不要做。**

**③ 第三层「差异化角度」在板块题上最好用。** 通用件说"主动放弃大家都盯的那个点"。板块题的共识焦点特别好识别——全网都在盯**板块涨跌幅**和**板块估值**，几乎没人算价差、没人查业务占比。所以差异化角度在这里几乎是白送的。

## 二、板块七类选题池（替换个股的七类，一次挑差异最大的 3 个）

**① 异动归因型（本品类主力，占比最高）**

这周为什么暴涨/暴跌，把当周波动的完整归因拆透。落点是账号已沉淀的方法论：**股价异动复盘的本质是信息解释服务**——观众要的是"今天/这周为啥这样"讲透，多空争议只是归因的抓手，不是主体。

- 命中：恐惧（跌）/ 不甘（涨）+ 信息服务。
- 成立条件：**动因有权威信源**（见 [sector-discovery.md](sector-discovery.md) 信号 B）。归因讲不清就换类型。
- 加分项：**多因叠加**。只有一个因的异动往上一层就见底了，撑不满 10 分钟；"行政令 + 出口占比 + 前期涨幅过大"三层叠起来才是深度稿。

**② 政策驱动型**

行政令、补贴、限产、集采、进出口管制落地后，谁真受益、谁只是名字沾。

- 命中：希望（受益方）+ 恐惧（受损方）。
- 独家性来源：**逐条对照政策原文的适用范围与公司披露的业务占比**。绝大多数号只读新闻标题，不读政策原文——`web_fetch.py` 抓原文就是独家性。
- 护栏：政策解读不能滑成"所以该配这个板块"（见文末合规）。

**③ 周期位置型**

库存周期第几阶段、这轮产能出清到哪了、供给主导还是需求主导。

- 命中：信息服务（弱动机），靠框架的可带走性撑。
- 独家性来源：**四阶段判定 + 一个具体的角色化故事**（酒厂和经销商、猪场和二次育肥、硅料厂和组件厂）。通用件的"手艺层"要求把判断压成能成像的意象，周期题必须靠这个活。
- 成立条件：观众听完能**一句话复述**（"农产品看供给不看需求"）。压缩不了说明还没想清楚，别上。

**④ 产业链价差型**

同一个涨价，谁在赚谁在亏。

- 命中：信息服务 + 优越感（"原来大家都理解错了"）。
- 这是七类里**独家性最高、最难被抄**的一类：要查上中下游各环节的价格、算价差方向。
- 天然反直觉：「油价涨利好还是利空化工」的正确答案是"看价差不看方向"，这本身就是一个能纠正很多人的框架。

**⑤ 伪概念揭穿型**

板块里蹭概念的名单。

- 命中：愤怒（被概念骗了）+ 优越感。
- 独家性来源：逐个查年报业务占比、公告澄清、交易所问询函。
- **两条硬约束**：① 必须有可查依据，拿不出就降级为客观描述（见文末合规第 3 条）；② 属于风险预警类，**别连做**——连着做会显得唱空成癖（继承通用件避坑）。

**⑥ 冷门重估型**

业绩涨一倍、股价十年零涨幅这类被忽视的板块。

- 命中：希望 + 优越感（"在没人看的地方翻石头"）。
- **本产线吸粉潜力最高的一类**：对照 huasheng 8.3，涨粉率前三名全是"有持仓盘、还没被全网铺满、能独家重算"的题，冷门重估型天然满足后两条。
- 风险：持仓覆盖面可能不足（冷门=拿的人少）。所以选板块阶段必须确认代表股里有散户认得的票，否则叫好不叫座。

**⑦ 板块对比型**

两个板块的跷跷板、这轮 vs 上一轮周期、A 板块的钱是不是从 B 板块抽走的。

- 命中：好奇 + 判断依据。
- 独家性来源：**两个板块的资金流对比**（`sector_board.py` 的 `main_net_inflows_yi`）+ 历史同期对照。
- 特别适合"我手里的 A 板块不动，全在涨 B"这种真实焦虑，代入感强。

## 三、准入自检追加项（通用件七条之外，板块题额外过五条）

1. **代表股落地关（板块题最容易翻车的一条）**：这个角度能不能点出 2-3 只散户认得的代表股，并且**角度本身跟这几只票有关系**？——不是随便报三个名字凑数，而是"这个逻辑落到这三家身上分别是什么结果"。做不到，这条角度就还是抽象的板块播报，5 秒完播必崩。
2. **归因完整关**：这个角度的因果链有没有断点？板块稿的全部信息价值在归因，链条里任何一环是"大概是因为"，那一环就得补搜或明确标为推测。
3. **传导到利润关**：这个角度有没有讲到"这件事怎么变成公司的利润或亏损"？停在"利好这个行业"就是正确的废话。**价差才是利润**——涨价传到谁那儿变成利润、传到谁那儿变成成本，必须说清。
4. **口径不串关**：这个角度依赖的数字，板块级和个股级有没有混用？（别拿几只龙头的涨幅平均代表板块涨跌幅，也别拿板块涨跌幅去说某只票）。混了就是数据造假，终审必打回。
5. **合规可讲关**：这条角度在**不给任何配置建议**的前提下能不能讲完整？如果讲完必然要落到"所以该配这个板块 / 该选哪只"才成立，**那它本身就不该做——换角度，不是换措辞。**

## 四、合规红线（选题阶段就要守，别指望写稿时补救）

板块题的荐股风险和个股题不同源，三条：

1. **不给板块配置建议、不给 ETF 选择建议。** ❌"××ETF 值得关注""这个板块适合小白配置""建议搭配网格策略""均衡摊大饼"。这几句在参考公众号里很常见，**它们是内容结构的参考，不是合规尺度的参考**。
2. **不给成分股的买卖判断或优劣排序。** ❌"这几家里最受益的是 XX""龙头首选 XX"。✅"这三家的这块业务占营收分别是 X%、Y%、Z%，沾不沾这个逻辑一看占比就清楚。"
3. **说"蹭概念"必须有可查依据**（年报业务占比、公告澄清、问询函），拿不出就降级为"这块业务在它营收里只占 X%，市场给的估值是不是给多了，见仁见智"。

判定口诀：**说清"这家沾不沾这个逻辑"= 内容；说"所以这几家里该选谁"= 荐股。**

## 五、输出格式

沿用通用件的三方案格式，**追加两个板块专属字段**：

```
## 选题 N：[一句话选题方向]

**核心角度**：这条视频讲什么、站什么立场
**命中动机**：恐惧 / 愤怒 / 希望 / 信息服务（一句话说清戳的是哪根神经）
**群体共鸣 / 对立面**：点名的是哪一群人（要落到具体票或具体时点）、站谁这边打谁的脸
**比较优势**：蛋炒饭凭什么讲这条比别人好（1-2 个）
**选题池**：属于板块七类里的哪一类
**独家框架**：←【板块专属必填】用的是价差表 / 周期阶段 / 伪概念清单 / 共识聚合，还是别的；一句话说清全网没人这么切过在哪
**代表股落点**：←【板块专属必填】2-3 只散户认得的票 + 这个逻辑落到每一家分别是什么结果
**开场钩子**：前 5 秒的具体第一句（含板块名 + 代表股名 + 一个数字或反差）
**内容主线**：3-4 个 bullet，讲清论证脉络（归因 → 传导 → 位置 → 分化）
**预估热度**：⭐⭐⭐⭐☆ + 一句话（动机强弱 + 独家性余量 + 反直觉强度）
**适合人群**：谁会点这条
```

三个方案给完，一句话邀请用户选择，然后**停下来**。三个都落在同一类（比如三条都是异动归因）算不合格，重挑。
