# 证据截图（口播稿定稿后自动跑）

口播稿里每一个"说了就得拿得出来"的事实，都要留一张**权威出处**的截图和原链接。截图有两个用处：

1. **成片素材**：财报表格高亮、政府公告原文、证券报和官方媒体的报道、券商研报结论，是知识类视频最有说服力的 B Roll（分镜里的"新闻引文 / 报告高亮"镜头）。观众一眼看到"这是公司公告""这是证券时报"，信任感是自制图卡给不了的。
2. **事实留档**：网页会改、会删，PDF 链接会失效。截图和原链接存下来，评论区有人质疑"数据哪来的"，或者复盘要回溯出处时，翻证据清单就能找到。

产出统一落在该视频的 `参考资料/证据截图/`，入口是那里的 `证据清单.md`。

## 一、什么时候跑

**阶段三，用户确认最终标题之后，和封面同步跑。** 这时文稿已经定稿，引用了哪些数字不会再变。不需要单独问用户要不要截，默认就做。

- 文稿后来又改了（加了新数字、换了信源）：只补跑新增或改动的条目（`--only`），旧的会跳过。
- 用户直接拿一份外来稿进阶段四：先按本文挑证据跑一遍，再派分镜子 agent，让分镜能用上截图。

## 二、只收权威出处（硬规则）

截图要拿到成片里给观众看，出处本身就是论据。**雪球帖子、东方财富号文章这类截图放进视频，等于告诉观众"这是网友说的"，没有引用价值，一律不截。**

| 等级 | 收不收 | 包括 |
|---|---|---|
| **A 官方原文** | 首选 | 公司财报和公告、投资者关系活动记录表（巨潮资讯 `cninfo.com.cn`、上交所、深交所、北交所、港交所披露易）；政府和监管部门原文（`*.gov.cn`：财政部、税务总局、证监会、工信部、地方政府和生态环境局）；期货交易所（广期所、上期所等） |
| **B 权威媒体与研报** | 可以 | 官方媒体（新华社、新华财经、人民网、央视、中新社、经济日报）；四大证券报（证券时报、中国证券报、上海证券报、证券日报）；主流财经媒体（第一财经、财新、21世纪经济报道、经济观察报、界面、澎湃、每日经济新闻、财联社）；券商研报原文（新浪财经研报中心、东方财富研报中心）；权威行业数据商（SMM 上海有色网、Mysteel 我的钢铁网） |
| **C 自媒体与社区** | **不收** | 雪球（帖子、评论、个股页）、东方财富股吧和东方财富号（caifuhao）、百家号、网易号、搜狐号、新浪看点和新浪财经头条自媒体、微博、今日头条、知乎、B 站专栏、公众号、腾讯新闻转载、汽车之家车家号、九方智投等 |
| 未分级 | 默认不收 | 不在上面名单里的域名（行业垂直网站、地方小报、券商以外的机构官网……）。人工确认是权威出处后，在条目里写 `tier` 和 `tier_reason` 才放行 |

脚本按域名自动判级（名单在 `evidence_capture.py` 的 `TIER_*`），C 级和未分级的链接会被跳过，状态记为"🚫 拒截"。

几条容易判错的：

- **同一个站点不同频道等级不同**：`finance.eastmoney.com` 的资讯和 `data.eastmoney.com/report` 的研报原文能收，`caifuhao.eastmoney.com` 和 `guba.eastmoney.com` 不收。`finance.sina.com.cn` 的新闻频道能收，`/stockzmt/`、`/wm/` 自媒体频道不收。网易、搜狐的 `/dy/`、`/a/` 是自媒体号，不收。
- **自媒体转载权威内容，去找原发**。百家号上一篇"转自新华财经"的文章，截的是百家号，没有用。去原发媒体的网站找原文；找不到原文，就当这个事实没有可截的出处（见第五节）。
- **研报转述**：研报原文拿不到时，截 B 级媒体对研报的报道，`source` 写明"转述 XX 证券研报"。自媒体对研报的转述不收。
- **行情数据**：雪球、东方财富的个股页属于第三方行情，不当证据截。要截就截交易所官网（深交所个股页 `szse.cn/certificate/individual/index.html?code=<代码>`、港交所 `hkex.com.hk/Market-Data/Securities-Prices/Equities/Equities-Quote?sym=<代码>`），并核对页面口径（深交所显示的是静态市盈率，和稿子常用的 TTM 不一样）。行情变化快，稿子里的估值数字更适合在成片里做自制数据卡，标注"数据来源：交易所，截至 X 月 X 日"。
- **雪球散户原话**：稿子里"评论区有网友说……"这类叙事可以留，但它是情绪素材，不是证据，不截图。

## 三、挑哪些证据

不是稿子里每个数字都截。挑的标准：**这个事实在视频里值不值得给观众看原件**。优先级从高到低：

1. **公司自己的披露**：财报（营收、归母净利、扣非、毛利率、现金流）、业绩预告、重大公告、投资者关系活动记录表（公司口径的经营说明，比如资源自给率、成本结构、产能进度）。用 `cninfo_announcements.py` 查链接，`--ir` 查投资者关系记录。
2. **政府和监管原文**：税率、退税、补贴、监管文件、审批公示。
3. **官方媒体和证券报的报道**：行业事件、价格异动、公司回应。
4. **券商研报和权威数据商**：机构预测、行业供需和成本数据。

**同一个数，有一手就不截二手**。财报里有的数截财报，不截转述它的新闻。

不用截的：纯观点句（"我认为……"）、自己推算的数（如"按三季度速度算一整年 30 亿"，清单里引用它的原始输入即可）、同一个数已经截过的重复引用。

## 四、写证据清单输入（manifest）

写在 `参考资料/证据截图/证据清单_输入.json`。字段说明见 `scripts/evidence_capture.py` 文件头，核心是这几个：

```json
{
  "project": "<最终标题>",
  "items": [
    {
      "id": "01", "name": "三季报主要会计数据", "kind": "财报",
      "url": "http://static.cninfo.com.cn/finalpage/2026-10-16/1225607211.PDF",
      "source": "赣锋锂业2026年三季报（巨潮资讯）",
      "quote": "三季度归母净利润7.5亿……三季度只剩不到8亿",
      "highlight": ["755,094,599.37", "787,643,773.92"],
      "pages": [2]
    }
  ],
  "unsourced": [
    {"quote": "稿中原句", "current_source": "目前只有百家号转载", "suggestion": "改稿或补权威出处"}
  ]
}
```

写法要点：

- **按稿子的叙述顺序编号**。分镜子 agent 拿到清单能按顺序对上段落。
- **url 先从抓取档案里找，找不到权威的就专门搜**：阶段一、二跑过的 `web_search.py` 结果在 `参考资料/抓取数据/web_search*.json`，用稿中的关键数字在 `content` 字段里反查，看 `website` 和 `url` 是哪一级。档案里只有 C 级时，带上权威媒体名再搜一轮（如 `"<关键数字> 证券时报 上海证券报 第一财经"`、`"<政策名> 财政部 公告 原文"`），结果存成 `web_search_权威信源.json`。不要凭记忆写链接。
- **写完先跑 `--check`**，确认每个链接都是 A/B 级再截。
- **highlight 必须是原文的字面写法**，不是稿子里的说法。稿子念"7.5亿"，财报里是"755,094,599.37"；稿子念"跌了将近12%"，原文是"11.79%的跌幅"。财报 PDF 先用 pymupdf 读一下那页的文字确认写法再填。拿不准就填原文里一个短而独特的片段（4-12 个字）。
- **财报 PDF 尽量填 pages**：三季报"主要会计数据"在第 2 页，年报摘要在第 3-4 页。不填就全文搜，第一处命中可能落在目录或别的表。
- **给容易打不开的页面加 alt_urls**：第一财经桌面页、部分政府网站偶尔截图超时或返回空页，同一篇报道常有别的权威转载（中新网转载证券时报、中国证券网是上证报原文、各地税务局都转载同一份财政部公告），填进 alt_urls，脚本会依次尝试。alt_urls 也只能填 A/B 级。
- **quote 抄稿子里的原句**。证据清单的价值就是"稿中这句话 ↔ 这张截图"的对应。

## 五、找不到权威出处的事实，写进 unsourced

有些说法搜遍了也只有自媒体在讲（典型的是"不完全统计"的订单数、自媒体自己汇总的成本表、对研报的二手转述）。这类说法**不截图**，在 manifest 的 `unsourced` 里逐条写清楚：稿中原句、目前只有什么出处、建议怎么处理。它们会出现在 `证据清单.md` 顶部的"待补权威信源"表里。

处理建议三选一，交给用户定：

1. **改稿**：换成有权威出处的说法（比如"6 家头部电池厂排产同比多了将近60%"只有自媒体出处，改成研报原文里的口径）。
2. **降级表述**：把具体数字改成定性说法（"自给率60%"只有百家号出处，公司记录表只说"资源自给率持续提升"，就按公司原话说）。
3. **删掉**。

**不要为了凑截图把自媒体链接塞进来，也不要因为截不到图就当作有出处。** 待补清单在阶段三收尾时要告诉用户。

## 六、跑脚本

```bash
EVI="$DIR/参考资料/证据截图"
# 先查等级
python3 "$SKILL_DIR/scripts/evidence_capture.py" --manifest "$EVI/证据清单_输入.json" --out-dir "$EVI" --check
# 截图
python3 "$SKILL_DIR/scripts/evidence_capture.py" --manifest "$EVI/证据清单_输入.json" --out-dir "$EVI"
# 只重跑失败或改过的几条
python3 "$SKILL_DIR/scripts/evidence_capture.py" --manifest "$EVI/证据清单_输入.json" --out-dir "$EVI" --only 09,10 --force
```

查财报和公司披露链接：

```bash
python3 "$SKILL_DIR/scripts/cninfo_announcements.py" 赣锋锂业 --keyword 三季度报告
python3 "$SKILL_DIR/scripts/cninfo_announcements.py" 002460 --keyword 年度报告摘要 --start 2023-01-01 --end 2023-12-31
python3 "$SKILL_DIR/scripts/cninfo_announcements.py" 赣锋锂业 --ir     # 投资者关系活动记录表
```

十几条大约 4-6 分钟（网页每条要等 JS 渲染）。条目多就放后台跑，期间做封面。依赖 `playwright`（和 `web_fetch.py` 共用 Chromium）、`requests`、`pymupdf`（`pip install pymupdf`，官方源慢就加 `-i https://pypi.tuna.tsinghua.edu.cn/simple`）。

每条产出：

- 网页：`NN_<名>_首屏.png`（带媒体 logo、标题、日期、来源行，适合"新闻引文"镜头）+ `NN_<名>_高亮.png`（关键词所在段落，黄底红框）。关键词在页面里相距较远时会多出 `_高亮2`、`_高亮3`。
- PDF：`NN_<名>_第X页.png`（整页，已高亮）+ `NN_<名>_高亮_pX.png`（关键词那几行的横条裁切），原文 PDF 存进 `原文/`。
- `证据清单.md` / `证据清单.json`：顶部是待补权威信源表；每条写稿中原句、来源、权威等级、原链接、实际截图链接、页面标题、抓取时间、关键词命中、截图自检结果、状态和文件链接。

截图按 2 倍像素输出（网页 2880 宽、PDF 约 1190 宽），放大到 1080p 不糊。

## 七、跑完必须检查

脚本会做两项自检：关键词有没有命中；高亮图里看不看得到高亮、是不是空白图。没通过的条目标成 ⚠️ 部分。这两项通过了，也不代表截得对，还要逐条看：

1. **状态**：`证据清单.md` 顶部有成功、部分、失败、拒截的计数。
   - 🚫 拒截：链接不是 A/B 级。去找权威原发；找不到就把这条挪进 `unsourced`。
   - ❌ 失败：被拦截、超时或页面已删。换一个权威转载链接（填 alt_urls）重跑。
   - ⚠️ 部分：关键词没命中（多半是 highlight 写成了稿子的说法），或截图自检没过（看"截图自检"那一行写了什么）。改完重跑。
2. **打开主截图看一眼**（`_高亮.png` / `_高亮_pX.png`）：高亮的是不是稿子说的那个数？有没有被弹窗、广告盖住？首屏上媒体名称和日期是否清楚？
3. **核对实际截图链接**：用了 alt_urls 时，条目的 `name` 和 `source` 要跟实际截到的媒体一致（比如原链接是第一财经、实际截的是中新网，就把名字和来源改成中新网）。
4. **行情页会变**：交易所行情截图反映的是抓取那一刻的价格。发布前重抓了行情、稿子改了数，行情截图也要 `--force` 重跑。

检查完，在 `视频基础信息.md` 元信息头填上证据截图入口、成功条数和待补条数，并在阶段三收尾时把待补权威信源的清单告诉用户。

## 八、和分镜的衔接

阶段四派分镜子 agent 时，把 `参考资料/证据截图/证据清单.md` 作为一样输入一起给它：清单里每条都有稿中原句，分镜切到那句话时直接用对应截图做"新闻引文 / 报告高亮"镜头，不要让花生 AI 生成一张假的财报图。待补权威信源表里的说法没有截图，分镜里用自制数据卡或纯口播，不要配截图。
